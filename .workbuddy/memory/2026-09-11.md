# 2026-09-11

## 首页 Cover Flow 卡片视觉迭代（app/coverflow.css）

**需求**：卡片不要圆角矩形；下方倒影要更清晰；Apple 味更浓。

**结论/做法**：
- 卡片 `border-radius: 0` 保持直角（上一轮已置 0），并新增**通栏品牌色底边（10px，`--cover-color`）**强化"印刷品"直角感。
- 卡片改为**不透明**白面（原来是半透明叠加，会透出相邻卡片文字，看起来发灰发脏）：
  `radial-gradient(品牌色 74% 透明) ×2 + linear-gradient(180deg, var(--card) ...)`，
  配 Apple 式多层柔和投影（1/2/10/28/60px 四档），去掉旧的 `2px 3px 0` 硬边纸感阴影。
- 文案块 `align-self: end`：标题/摘要/日期整体压到卡片下半部
  （Apple 产品磁贴那种"下方文案"排版），顺带让倒影里有内容可看。
- 倒影用 `-webkit-box-reflect`；**遮罩方向是反的**：元素底部透明、顶部不透明才是"贴卡清晰、向下渐隐"。详见 skill `local-design-screenshots`。
- 版面：`--card-size: clamp(16rem, 34vw, 28.5rem)`，`.coverflow-stage` 高度 = 卡片宽 ×1.7，
  卡片 `top: 33%`，给倒影预留空间；倒影在翻页器之前渐隐。1440×900 下 section 正好 900px（一屏）。
- 去掉纸纹/斜线等拟物纹理；`.cover-paper::after` 从斜色线改成通栏色带；标题字距 -0.055em → -0.028em。
- 深色模式单独覆盖倒影遮罩（深底上白字倒影要更强才看得见）。

**踩坑**：
- 移动端媒体查询里残留 `.cover-copy > strong { font-size: clamp(2rem,8vw,3rem) }` 导致标题多折一行，已改 `clamp(1.5rem, 5.6vw, 2.1rem)`。
- 中文标题不要用 `max-width: 12ch`（ch 对 CJK 太窄），已删除。

**工具**：新建 `.pet-runs/shots/shoot.mjs`（无头 Chrome + CDP 截图，支持 region 放大、注入 CSS/JS、eval 读 DOM）。

## 追加：分类栏字号调大

**需求**：分类栏目（`.category-chip`）字体偏小。

**改动**（`app/coverflow.css`）：
- `.category-chip` 字号 `0.7rem → 0.85rem`（11.2px → 13.6px，+21%），`min-height 2rem → 2.3rem`，
  `padding 0.3rem/0.65rem → 0.35rem/0.85rem`，补 `display:inline-flex + gap:0.45rem`；
  `.category-filter` 纵向 padding `0.34rem → 0.45rem`。
- 选中态圆点曾被 `globals.css` 里的 `.category-chip[aria-pressed='true'] .chip-dot { background:#ffffff }`
  写成白色 —— 那是旧「深色药丸」时代的规则，换浅灰药丸后完全看不见，已在主题层覆盖回 `var(--chip-color)`。

**教训**：本项目是 `globals.css`(基础) + `coverflow.css`(主题层) 双层，同一选择器两边都可能有定义且值不同。
改样式"没生效"时先 grep 另一个文件并用 `getComputedStyle` 读实际值，别猜。

## 追加：删掉首页 hero「每日更新」，上来就是卡片

**需求**：主页面不要 hero，进页面直接看到封面卡片。

**改动**：
- `app/page.tsx`：删掉 `<section class="editorial-hero">` 整块；补一个 `<h1 className="sr-only">Daily Knowledge 每日更新</h1>`
  保住页面唯一 h1（a11y/SEO），视觉上不可见。
- `app/coverflow.css`：
  - 删除 `.editorial-hero*` 全部规则、`@keyframes title-rise`、移动端 hero 覆盖、reduced-motion 里的 `.editorial-hero *`。
  - `.site-shell` 改成 `display:flex; flex-direction:column; min-height:100svh`；
    `.coverflow-section` 改成 `flex: 1 0 auto; min-height: 0`（**`1 0 auto` 不能写成 `1`**，
    否则空间不够时区块会被压缩，`overflow:hidden` 会把倒影/翻页器切掉）。
  - 区块上下 padding 收紧到 `clamp(1.25rem,2.5vh,2rem) / clamp(1.5rem,3vh,2.25rem)`。
  - `.coverflow-stage` 尺寸改为**双约束**，让整页永远恰好一屏：
    ```css
    --cover-lift: 220px; /* 页头68 + 筛选栏52 + 区块留白~50 + 翻页器~47 */
    --card-size: min(clamp(16rem,34vw,28.5rem), calc((100svh - var(--cover-lift)) / 1.62));
    height: calc(var(--card-size) * 1.62);
    ```
  - `.cover-card` 加 `container-type: inline-size`，标题 `font-size: 10cqw`
    —— 卡片被视口高度压小时标题跟着缩，避免溢出/多折行（`cqw` 前保留 clamp 作为不支持时的兜底）。
  - 卡片 `top: 33% → 36%`（H/W 从 1.7 改 1.62 后重新配平上下留白）；倒影遮罩终点 `t=0.32 → 0.46`。

**验证**：800/900/1050/1200（1440 宽）、390×844、768×1024、1920×1080 全部 `scrollHeight === innerHeight`，即**任何高度都无滚动条**。
