今日 AI 技术进展

OpenAI 于昨日正式发布了 GPT-5 模型，这是继 GPT-4 之后的重大升级。新模型在推理能力、代码生成和多语言理解方面均有显著提升。

核心改进

  • 推理能力：在复杂逻辑推理任务上准确率提升 30%
  • 代码生成：支持更长上下文窗口，一次生成完整项目结构
  • 多模态：原生支持图像、音频和视频理解

性能对比

测试项目 GPT-4 GPT-5
MMLU 准确率 86.4% 92.1%
HumanEval 通过率 67% 85%
上下文窗口 128K tokens 256K tokens

"GPT-5 代表了我们向 AGI 迈出的重要一步。"——Sam Altman

代码示例

以下是使用 GPT-5 API 的简单示例：

import OpenAI from 'openai';

const client = new OpenAI();

const response = await client.chat.completions.create({
  model: 'gpt-5',
  messages: [
    { role: 'user', content: '解释量子计算的基本原理' }
  ]
});

console.log(response.choices[0].message.content);
