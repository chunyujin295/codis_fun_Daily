# Daily Paper 个人化视觉重设计需求

## 页面概述

- 页面：公开首页、文章阅读页、登录页、管理后台、智能体文章模板
- 操作类型：修改现有页面
- 核心目标：摆脱常见产品模板的规范化观感，形成一眼可辨认的个人视觉语言

## 已确认需求

- 保留现有内容浏览、栏目筛选、文章阅读、主题切换和后台功能。
- 保留首页已经精简的短文案，不恢复大段宣传文字。
- 同时覆盖浅色与深色主题，并保持移动端可用。
- 风格变化必须落到版式、字体层级、边线、形状、节奏与交互细节，不只是换色。
- 视觉气质参考 Apple 官网：大留白、聚焦内容、滚动进入与层级过渡动画。
- 时间轴参考 iPod 的歌曲切换体验：当前文章明确居中，前后内容保留空间提示，并支持连续切换。

## 当前问题

- 大量圆角卡片、柔和渐变、居中容器与统一阴影形成了常见 SaaS 模板感。
- 播放器区域曾硬编码为黑色，未响应浅色与深色主题。
- 上一版使用“当前文章 + 文章队列”，不符合 Cover Flow 的横向三维封面翻阅模型。
- 首屏和内容区存在解释页面用途的多余文案，削弱留白与侘寂感。

## 架构决策

| 决策点     | 选择                                                                    | 理由                                                       | 放弃的方案                         |
| ---------- | ----------------------------------------------------------------------- | ---------------------------------------------------------- | ---------------------------------- |
| 时间轴交互 | 横向平移式 Cover Flow：所有封面保持正面，中心放大，两侧平移、缩小并叠放 | 按用户参考强调连续平移和当前焦点，不使用翻面动作           | Y 轴翻转、纵向文章队列、静态卡片树 |
| 动画实现   | React 状态配合 CSS transform/opacity，并遵守 reduced-motion             | 不增加依赖，生产构建稳定，键盘与触控均可退化使用           | 引入重型动画库或只做滚动淡入       |
| 视觉方向   | Apple 式动效秩序 + 侘寂材质与大留白                                     | 以不对称、低饱和纸张色和细微纹理形成个人气质，同时保持克制 | 常见 SaaS 卡片墙、纯黑科技风       |
| 主题实现   | Cover Flow 全部颜色来自共享主题令牌                                     | 保证浅色和深色模式同步影响背景、封面、文字、反射与控件     | 播放器区域硬编码固定黑色           |

## 交互说明

- 首页首屏只保留标题，以大面积留白建立节奏。
- 所有文章封面始终正面朝向；当前封面居中放大，两侧封面密集叠放，仅通过横向平移、缩放、透明度和层级完成切换。
- 拖动过程实时跟手，松手后吸附到最近文章；同时支持点击封面两侧、滚轮、前后按钮和方向键切换。
- 滚轮事件采用边界接管：仍有封面可切换时只驱动 Cover Flow；到达首尾并继续向外滚动时才交还页面，禁止同一次滚轮事件同时移动页面和封面。
- 切换动画不影响“查看文章”链接；减少动态偏好开启时禁用位移与缩放。
- 栏目筛选后自动从筛选结果第一篇开始，空结果提供明确提示。
- 删除“页面是做什么的”“如何操作”等可由界面自行表达的说明文字。
- 日期只在文章卡片内部显示；首屏、大号标题区与卡片外导航均不重复日期。
- 封面采用圆角矩形的拟物唱片套语言：纸张纤维、套封厚度、压痕、边缘高光、实体投影和镜像反射，并同时适配深浅主题。
- 圆角只用于卡片与按钮；日期文字、导航容器、滑杆外壳、图片、引用、代码块、表格和输入框保持平直边缘。
- 阴影保持轻量，只用于表达卡片与按钮的微弱高度差，不制造厚重悬浮效果。
- 删除卡片下方的数字进度与范围滑杆；前后按钮之间使用无文字的惯性珠动画反馈切换。
- 文章简介直接展示在当前封面中，删除封面下方的独立简介卡，并适当增大封面面积。
- 栏目筛选使用紧凑单行工具条，取消额外上下留白；滚动后吸附在站点导航下方，方便随时切换。
